Luciel 공부 웹사이트 - 첫 버전

파일:
- index.html: 사이트 전체가 들어 있는 파일

빠르게 확인하기:
1. index.html을 더블 클릭해 브라우저에서 열어 봅니다.
2. 사진 넣기, 가로/세로 전환, 필기, PNG 저장을 시험합니다.

인터넷에 무료 공개하기 (Vercel + GitHub):
1. GitHub 계정으로 로그인한 뒤 New repository를 선택합니다.
2. 저장소 이름을 luciel-study 로 정하고 Public을 선택해 만듭니다.
3. Add file > Upload files 를 누르고 index.html을 업로드합니다.
4. Commit changes를 누릅니다.
5. Vercel에 로그인하고 Add New > Project를 선택합니다.
6. 방금 만든 GitHub 저장소를 Import합니다.
7. 별도 빌드 설정이 필요 없는 정적 HTML이므로 기본 설정으로 Deploy합니다.
8. 배포가 끝나면 제공되는 .vercel.app 주소를 엽니다.

주의:
- 공개 저장소의 파일과 사이트는 인터넷에 공개됩니다. 개인정보나 비밀번호를 올리지 마세요.
- 이 버전은 로그인이나 서버 동기화가 없습니다. 노트는 사용 중인 브라우저에 저장되며, 다른 기기와 자동으로 동기화되지 않습니다.
- 브라우저의 사이트 데이터/캐시를 지우면 저장된 노트가 사라질 수 있으니 중요한 노트는 PNG로 저장하세요.
